![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

PostgreSQL 18 — a powerful, open source object-relational database server.

The database can be kept on an external drive with the **Data directory** option,
which suits installs on an SD card. This has been tested only on Home Assistant
Supervised. See [DOCS.md](DOCS.md#external-drive).
